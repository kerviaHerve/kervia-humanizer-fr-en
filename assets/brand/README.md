## English

These two logos come from the Kervia general kit v02 supplied by Hervé on 1 November 2026, dated 31 October 2026. This is the replacement brand reference for this repository's presentation.

The selected family is Kervia, the approved “01 Équilibre / 02 Jonction” identity. The master files are copied unchanged, without redrawing, recolouring, cropping or recomposition. The light-background file uses green lettering; the dark-background file uses soft white lettering. The chevron and the dot on the i keep their original colours.

The project title remains separate text. No new official Humanizer logo is created. See [provenance.json](provenance.json) for source paths within the kit and hashes.

A GitHub README is documentation, not a Kervia application. GitHub controls body typography and layout; the logos are self-contained vector paths. The kit's React/Mantine application guidance is not applied here. No existing website, application or global skill is migrated.
